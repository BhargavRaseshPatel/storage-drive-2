# ✨ Store My Data – File Storage Dashboard ✨

A modern file management web application that allows users to upload, organize, and manage their personal data such as documents, images, and media files.

🌐 **Live Application:** https://store-my-data.com/

---

## 🚀 Features

- 📂 Upload and manage files  
- 🗂️ Organized file categories:
  - Documents  
  - Images  
  - Media  
  - Others  
- 📊 Interactive dashboard with storage insights  
- 🔍 Search functionality for quick access  
- 📄 Detailed file view (name, size, type, date)  
- ⬇️ Sort files by latest uploads  
- 🎨 Clean and modern UI  
- 📱 Fully responsive design  

---

## 📊 Dashboard

The dashboard provides a quick overview of your storage:

- Visual representation of file distribution  
- Storage usage insights  
- Category-wise breakdown of files  
- Quick stats for:
  - Total items  
  - Total storage used  

---

## 📁 File Management

- Grid-based file layout for better visibility  
- Supports multiple file types such as:
  - PDF  
  - DOCX  
  - Images  
- Each file includes:
  - File name  
  - File size  
  - Upload date and time  
  - File type indicator  

---

## 🧱 Tech Stack

- **Frontend:** Next.js 15, TypeScript  
- **Styling:** Tailwind CSS  
- **UI Components:** shadcn/ui  
- **Backend & Storage:** Appwrite  
- **Deployment:** Vercel  

---

## 🎯 Purpose

This project is designed to provide a simple and efficient way to store and manage personal files in one place with a user-friendly interface and real-time insights.
